# ADR-0007: 저장 안 한 채 끝낼 때는 확인 창으로 묻는다

- 상태: 채택 (Accepted)
- 날짜: 2026-09-29
- 대체: ADR-0001 §4 의 "저장 안 한 것이 있으면 ctrl+c 를 한 번 더 눌러야 끝난다"

## 배경 (Context)

저장 안 한 것이 있을 때 ctrl+c 를 누르면 띠에 "한 번 더 누르면 버리고 끝낸다" 를 적고, 한 번 더 누르면
끝냈다. 그 사이의 상태는 판의 `quitAsked` 필드였고, 다른 키를 치면 모드 화면마다 `forgetQuit` 로 거두었다.
띠의 알림은 눈에 덜 띄고, 저장하고 끝내려면 ctrl+s 와 ctrl+c 를 따로 눌러야 했다.

창은 이미 화면이다(ADR-0005). 묻는 것도 창 하나로 세울 수 있다.

## 결정 (Decision)

- 저장 안 한 것이 있을 때 ctrl+c 를 누르면 끝내기 확인 창(`viewQuit`, quit.go)이 뜬다. 없으면 바로 끝낸다.
- 버튼은 셋이다: 저장 후 끝(s) · 버리고 끝(d) · 취소(Esc).
- 고르는 길은 셋 다 연다: 버튼의 글자 키, 좌우 방향키로 옮겨 Enter, 버튼 누름. 창 바깥을 누르면 취소다.
- 처음 짚은 버튼은 잃는 것이 없는 "저장 후 끝" 이다.
- 창이 떠 있을 때 ctrl+c 를 한 번 더 누르면 버리고 끝낸다. "두 번 누르면 끝" 이 손에 익어 있고, 터미널
  프로그램이 흔히 그렇다.
- 저장에 실패하면 끝내지 않고 창을 닫는다. 까닭은 띠에 적힌다(save). 그린 것을 잃지 않는다.
- 창이 떠 있을 때 ctrl+s 는 저장만 하고 창을 둔다. 저장되어도 창은 스스로 닫지 않는다.
- 취소하면 창을 연 모드 화면으로 돌아간다. 글자 모드에서 ctrl+c 를 눌러도 뜨고, 그때 s · d 는 글자가 아니라
  버튼이다.
- `quitAsked` 필드와 `forgetQuit` 는 없앴다.

## 결과 (Consequences)

- 끝낼지를 묻는 것이 눈에 띄고, 저장하고 끝내는 것이 한 번에 된다.
- ctrl+c 를 두 번 누르면 끝나는 것은 전과 같다. 다만 두 번째 누름은 창이 받는다.
- 판에 끝내기를 위한 상태가 없다.
